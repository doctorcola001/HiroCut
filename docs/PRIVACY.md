# 隐私说明

HiroCut在设备上处理用户通过系统文件选择器授予访问的视频。

- 无账号、广告、分析、远程配置或云上传；应用Manifest无INTERNET权限。
- 文件由用户通过系统选择器导入、保存。视频URI不转换为猜测的真实路径。
- 本地记录当前来源授权、选区草稿和设置，以便恢复。临时授权来源可能需要重新选择。
- 缩略图仅在内存缓存；编码中间文件和待保存成品位于应用私有目录。
- 已校验但尚未保存的成品可在重启后恢复保存；取消、失败和启动恢复会清理不再使用的中间文件。
- 源文件只读。对已有非空或无法确认安全的目标文件拒绝写入。
- 输出不保留字幕、附件或可选源元数据（含定位），不把这一行为作为所有可能元数据字段的全面清理承诺。
- ExoPlayer和Transformer显式关闭可选平台诊断上报，应用禁用备份。

此说明针对仓库当前实现；设备系统和用户选择的文件提供器有各自行为。应用不提供云传输功能。
